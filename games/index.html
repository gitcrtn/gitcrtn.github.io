ミニゲーム集

遊び方

遊びたいゲームのパネルをクリックすると、ゲームが始まります。

キーボードでは、矢印キーでゲームを選び、Enter キーで始めます。

ゲームパッドでは、十字キーでゲームを選び、A ボタンで始めます。

ゲームのメニュー（START）で「終了」を選ぶと、この一覧に戻ります。

キーボード

ゲームパッド

ゲームパッドを接続して遊ぶこともできます。接続後にいずれかのボタンを押すと認識されます。

A / B / X / Y ボタンはボタンの配置で割り当てており、右が A、下が B、上が X、左が Y です。ゲームパッドの印字とは異なる場合があります。

START ボタンでゲームのメニューを開きます。Xbox ではメニューボタン、PlayStation では OPTIONS ボタンが START ボタンにあたります。

SELECT ボタンは使用しません。Xbox ではビューボタン、PlayStation では SHARE ボタンまたは CREATE ボタンが SELECT ボタンにあたります。

スマホ

画面の下の仮想パッドで遊びます。スティックは、ゲームによって出ます。

音

  • 画面を触るか、キーを押すまで、音は出ません。
  • 音量と消音は、PC は画面の右上、スマホは仮想パッドの上にあります（全ゲーム共通）。
  • iPhone / iPad では、消音（マナーモード）の場合は鳴りません。

セーブ

このブラウザに残ります。ほかのブラウザや端末とは共有しません。ブラウザの設定画面から消去できます。
